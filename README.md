# Node.js Backend Course Projects

Este repositorio contiene todos los proyectos y ejercicios desarrollados a lo largo de un curso completo de backend con Node.js. El contenido está organizado por secciones, siguiendo una progresión desde los fundamentos hasta la construcción de aplicaciones más complejas con buenas prácticas, testing y arquitectura limpia.

El objetivo principal del repositorio es consolidar conocimientos prácticos en desarrollo backend moderno con Node.js, aplicando patrones reales utilizados en entornos profesionales.

## Contenido del repositorio

El repositorio está dividido en carpetas que corresponden a las distintas secciones del curso:

- **01-fundamentos**  
  Introducción a Node.js y primeros pasos con el entorno de ejecución, módulos y conceptos básicos.

- **02-bases**  
  Profundización en Node.js y primera toma de contacto con testing.

- **03-typescript**  
  Bases de Node.js utilizando TypeScript, tipado estático y configuración del entorno.

- **04-multiplication**  
  Aplicación de consola con lógica desacoplada y pruebas automatizadas.

- **05-NOC**  
  Proyecto de monitoreo aplicando testing y principios de Clean Architecture.

- **06-json-server**  
  Simulación de APIs y servicios para pruebas y desarrollo.

- **07-RestWeb**  
  API REST completa utilizando Clean Architecture, separación de capas y testing.

- **08-user-store**  
  Gestión de carga de archivos simple y múltiple en un backend Node.js.

- **09-github-webhooks**  
  Integración y seguridad de webhooks, validación de firmas y manejo de eventos.

- **10-serverless**  
  Introducción a Edge Functions y funciones serverless con Netlify.

- **11-websockets**  
  Fundamentos de WebSockets y comunicación en tiempo real.

- **12-websocket-front**  
  Cliente frontend para consumir servicios WebSocket.

- **13-socket-server**  
  Aplicación completa combinando API REST y WebSockets para un sistema de colas en tiempo real.

## Tecnologías y herramientas utilizadas

- Node.js
- TypeScript
- Express
- WebSockets
- Arquitectura limpia aplicada a backend
- Testing con Jest
- APIs REST
- Manejo de eventos y asincronía
- Webhooks y seguridad básica
- Funciones serverless
- Git y control de versiones

## Enfoque del curso

- Aplicación progresiva de buenas prácticas
- Código desacoplado y mantenible
- Uso real de Clean Architecture en Node.js
- Testing como parte fundamental del desarrollo
- Simulación de casos de uso reales en backend

## Propósito del repositorio

Este repositorio sirve como portfolio técnico y como referencia práctica de los conocimientos adquiridos en desarrollo backend con Node.js. Refleja la evolución desde proyectos sencillos hasta aplicaciones más completas y estructuradas, preparadas para entornos reales de producción.
